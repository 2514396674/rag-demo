# 语料目录

把要问的文档放在这里，支持三种格式：

- `.md`
- `.txt`
- `.pdf`（可提取文字的电子版；扫描件需要先 OCR）

## 已包含

`sample-handbook.md` —— 一份**虚构的示例员工手册**，用于让项目开箱即可运行。

## 换成你自己的文档

```bash
# 删掉示例，放入自己的文件
rm docs/sample-handbook.md

# 重新建索引（会自动检测到文档变化）
python rag.py --rebuild "随便问一个问题"
```

## 注意

- **扫描版 PDF** 提取出来是空的，需要先做 OCR（项目本身不含 OCR）
- 语料变了索引会自动失效重建，不需要手动删缓存
- `.index_*.json` 缓存里含文档全文，已在 `.gitignore` 中排除
